# Scribe

A premium dark-mode academic notebook for organising courses, chapters, topics and pages.

## Project status

Native Android application built with Kotlin, Jetpack Compose and Material 3. The initial implementation is being established from an empty repository.

## Planned architecture

- Course → Chapter → Topic → Pages hierarchy
- Block-based page editor with text, headings, equations, images, PDFs, video links, tables, code and audio attachments
- Room persistence, offline-first storage and autosave
- Search, tags, bookmarks, formula collection, revision mode and cross-links
- Export and backup/restore
- Dark graphite visual system with refined typography

## Build

Open the project in Android Studio and sync Gradle. Requires JDK 17 and Android SDK 35.
